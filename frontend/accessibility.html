Accessibility Statement

Last updated: August 2026

WorkBridge ETH is built to work for people using a keyboard, a screen reader, or browser settings like reduced motion — not just a mouse and default settings. Specifically, the site includes:

  • Visible keyboard focus on every interactive element — links, buttons, form fields — so you can see where you are while tabbing through the page.
  • Labeled form fields that are programmatically associated with their inputs, so screen readers announce what each field is for.
  • Reduced-motion support. If your operating system is set to reduce motion, the site's background animation and scroll effects scale back automatically.
  • Semantic structure and ARIA roles on dialogs (like the sign-in form) so assistive technology understands them as dialogs, with clear headings and live-region announcements for form errors.
  • Sufficient color contrast. Text colors are checked against WCAG AA contrast requirements in both light and dark theme.
  • Alt text on meaningful images, and a working, keyboard-reachable "back to top" control.

Known limitations

This is an evolving platform. Some newer or more complex screens may not yet meet the same bar as the core flows (sign-up, sign-in, dashboard, job applications). We're not aware of specific gaps at the moment, but we also haven't run a full third-party accessibility audit.

Let us know

If something doesn't work well with the tools you use to browse the web, we want to hear about it — it'll be treated as a real bug, not a low-priority request. Reach out with what you were trying to do, what happened, and what device/browser/assistive technology you were using, if relevant.
